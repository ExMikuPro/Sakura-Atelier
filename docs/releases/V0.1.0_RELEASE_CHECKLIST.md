## 手动硬件验收（需用户填写结果）

每项记录：MCU/板型号、macOS/工具版本、Commit/VSIX SHA256、探针、命令日志和观察结果；不提交 ST 账号或凭据。

1. 经典 CubeMX 6.x 选 MCU，新建项目，确认 .ioc、CMake、Arm 工具链和 main.c；缺固件包时报错清楚。失败保留目录，另选新目录或打开已有工程修复。
2. 使用候选包的 STM32 Build 分别构建 Debug / Release，确认 ELF 时间更新且没有烧录；核对工具路径和预设。
3. 托管 Run（OpenOCD）：核对固件、MCU、探针，先取消确认确保不写设备，再确认烧录/校验/复位并观察固件。
4. 兼容 CubeProgrammer 后端：单独验证编程、verify、reset；未验证前不宣称与托管 OpenOCD 相同。
5. Cortex-Debug：运行至 main、断点、单步、变量/寄存器，Stop/关闭 Host 后 OpenOCD 与 GDB 不残留；测试端口占用、拔掉探针。
6. .ioc 使用 CubeMX GUI 修改并重新生成，保护 USER CODE 后重建；CubeMX2 不支持。
7. PlatformIO：至少一个真实开发板，核对板/框架、多环境、Build/Clean/Test、确认 Upload、Debug、Monitor/Stop，检查官方 IDE 同时运行任务的冲突提示。
8. 无 PlatformIO Core / 缺 SDK 时检查错误引导，无自动安装；创建失败、取消与重试不覆盖用户文件。

- 审阅 dev 工具链 moderate 告警；确认发行人 ExMikuPro 在 Marketplace 的归属与权限。

- 明确确认后才允许推送、Tag、GitHub Release、Marketplace 上传；本任务未执行任何公开发布。
