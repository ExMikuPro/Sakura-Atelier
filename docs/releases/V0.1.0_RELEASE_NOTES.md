# Sakura Atelier v0.1.0 — First Public Preview

发布日期：待定。本文件为发布说明草稿，尚未创建 Tag 或公开 Release。

Sakura Atelier 将运行/调试配置、本机 SDK 自动发现、基础项目创建与嵌入式工具协作整合到 VS Code，目标是减少准备环境的重复操作，让开发者尽可能在 30 秒内进入编码状态。

## 本次预览提供

- 统一配置选择、Run / Debug / Stop、个人与项目配置、中英文界面。
- Python 虚拟环境、TypeScript 依赖初始化，以及 Node.js、Go、Rust、C/C++ 等基础项目模板。
- 经典 STM32CubeMX 6.x 工程创建和重新生成入口、CMake Debug/Release 构建、ELF 定位及烧录/调试集成。
- PlatformIO 多环境识别、开发板/框架选择、Build / Clean / Upload / Debug / Monitor / Test 入口。
- 复用 VS Code 原生任务、调试器及第三方扩展；不替代完整 IDE。

## 安装与依赖

首发验收平台为 macOS Apple Silicon，VS Code 1.85+。安装附件中的 VSIX 后重载窗口。源码构建使用 Node.js 22+、`npm ci`、`npm run package`。

需要按项目类型准备本机 SDK 与工具。嵌入式工作流依赖 PlatformIO Core，或 STM32CubeMX 6.x、CMake/Ninja、Arm GNU、OpenOCD / STM32CubeProgrammer；调试还需要对应语言调试扩展或 Cortex-Debug / 官方 PlatformIO IDE。

## 已知限制

- Java/Spring 与 C# 为实验性；数据库工作流暂不支持。
- Windows、Linux、Intel Mac、远程环境尚未完成原生端到端验收。
- STM32 托管 Run 在确认后通过 OpenOCD 烧录；Build 不烧录。兼容后端保留 CubeProgrammer 计划，两者需分别验收。
- 已有 STM32 CMake/Ninja + ARM GCC 15.3.1 生成 ELF、PlatformIO Core 6.2.0 及补全验证记录；真实硬件烧录/调试和 CubeMX 6.x 端到端生成仍待手动验收，不能视为通过。
- 创建失败保留目录，不覆盖重试；修复现有环境或使用新的目录。无自动安装系统 SDK。

## English

First Public Preview for macOS, Apple Silicon first. Sakura Atelier unifies run/debug configuration management, local SDK discovery, basic language project creation and collaboration with classic STM32CubeMX 6.x and PlatformIO. VS Code 1.85+ is required. Install the attached VSIX and reload; install external SDKs and debug extensions separately.

Java/Spring and C# are experimental. Databases are unsupported. Other platforms and remote development are not verified end to end. Hardware upload/debugging and real CubeMX generation require manual acceptance; existing CMake/ELF and PlatformIO Core validation does not imply hardware success. Managed STM32 Run flashes via OpenOCD after confirmation; Build only compiles.
